# Jevfast project submissions

This is the **issues-only public repository for [jevfast.com](https://jevfast.com)**, an independent showcase of creative projects built with TypeSafe AI's Jev model. The website source is maintained separately. This repository is not affiliated with TypeSafe AI.

## Suggest a project or video

[Submit a project or video](https://github.com/favoyang/jevfast-public/issues/new?template=new-project.yml) using the GitHub issue form. A GitHub account is required. Share the name or title, a public source URL, and a short explanation of how it uses Jev or what the video teaches. You can suggest your own work or someone else's; credit the creator.

Public demos, code, videos, screenshots and creator posts help us assess a submission. Evidence can be an idea, demo or available code. Interesting ideas and existing popularity are considered. [Check Candidates](https://jevfast.com/submit/#candidates) before submitting and do not resubmit an item already shown there. Inclusion is not guaranteed.

All issues are public. Do not include API keys, private files or personal contact details. Only link media you have permission to share.

Please use issues for submissions. Pull requests are not the submission workflow.
